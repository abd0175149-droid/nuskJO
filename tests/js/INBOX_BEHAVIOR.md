# سلوك صندوق المحادثات المحفوظ (E16.1)

مرجع إعادة هيكلة `Pages/WhatsApp/Inbox.vue` إلى مكوّنات (E16.4). كل بند هنا كان قائماً قبل الهيكلة ويجب أن يبقى بعدها. علّم البند ✅ بعد مطابقته في الواجهة الجديدة، وسجّل مكانه.

## القائمة
- [ ] بحث بالاسم أو الرقم بتأخير 400ms، وفلاتر: الكل، غير مقروء، تدخّل، بوت، بشري، الموكلة لي (`filter`).
- [ ] تصفية بالموضوع (`topic`)، وتنبيه «تظهر لك المحادثات التي تخصّ مجالاتك فقط» لمن لا يرى الكل (`seesAll`).
- [ ] عدّاد غير المقروء، وسطر الهوية: الرقم داخل `<bdi dir="ltr">`، أو `@username`، أو «رقم غير ظاهر» (E11).
- [ ] المعاينة، والوسوم (يدوي بإطار ذهبي وآلي رمادي)، والموكَّل إليه.
- [ ] الشارات: ⚠️ تدخّل، 📵 بلا رقم، 📣 من إعلان، سبب التدخّل (E07 `attention_reason` بنص `attentionReasons`)، 🤖 بوت / موقوف مؤقتاً / 👤 بشري، 👔 إدارة، عميل مسجّل، نافذة مغلقة، ⏳ الوقت الباقي (≤6 ساعات، أحمر ≤ساعتين، لما يحتاج تدخّلاً).
- [ ] الوقت النسبي لآخر رسالة.
- [ ] الاستطلاع كل 15 ثانية؛ بعد فشلين متتاليين شريط «تعذّر التحديث منذ …» يختفي عند النجاح.

## الأشرطة أعلى الصفحة
- [ ] شريط الحالة: ⛔ الإرسال موقوف (مع مصدر الإيقاف من `SUSPEND_SOURCES`، E10)، أو 🟢 البوت يعمل، أو 🟡 القناة مهيّأة والبوت مطفأ، أو 🟡 القناة غير مهيّأة، ورابط الإعدادات.
- [ ] ⛔ القناة متوقفة من جهة ميتا (`status.meta_blocked`، E08).
- [ ] 🔌 وضع التحويل منذ HH:MM (قاطع المزوّد، E12 `llm.state`، ويتحدّث من ردّ القائمة).
- [ ] تنبيه «المحادثة غير متاحة لك» القابل للإغلاق (E04، 403/404).

## الخيط
- [ ] فتح المحادثة: أحدث الرسائل ثم النزول للأسفل، و`POST /read` إن كان فيها غير مقروء ويملك الموظف الرد.
- [ ] `?conv=ID` في الرابط يفتح المحادثة مباشرة (إشعارات، طلبات التسعير)؛ خارج النطاق يزيل `conv` بـ `history.replaceState` ويظهر التنبيه.
- [ ] رقم تسلسل (`seq`) يُهمل أي ردّ وصل بعد الانتقال لمحادثة أخرى.
- [ ] الاستطلاع بـ `after` و`since`: الجديد يُلحق بلا تكرار، وتحديثات الحالة تُطبَّق (status وerror وmedia)، و`gap` يعيد الفتح. طلب واحد في كل مرة (`inflight`).
- [ ] قرب الأسفل (150px): ينزل ويعلّم مقروءاً إن كانت الصفحة ظاهرة ومركّزة؛ وإلا زر «رسائل جديدة (N) ↓».
- [ ] الصعود لأعلى (80px) يحمّل الأقدم بـ `before` مع حفظ موضع القراءة، وزر «↑ رسائل أقدم».
- [ ] رسائل النظام (`is_system`، تحديث هوية E11) شريط وسطي لا فقاعة.
- [ ] الفقاعة: المرسل 👤 (موظف)، والاقتباس ↩️ (E11)، والنص، والمرفق `MediaChip` وعارضه `MediaViewer` بعلامة مائية (E14)، والوقت، والمصدر (بوت/موظف/نظام/محقونة)، وفشل، و🛡️ حُجبت (E15)، وغير مؤكد (E12)، ونص الخطأ للفاشلة والمحجوبة.
- [ ] الألوان: الوارد أبيض، والبوت أخضر، والنظام رمادي، والموظف ذهبي، والمحجوبة حمراء.
- [ ] الملاحظات 📝 أسفل الخيط.

## الرأس
- [ ] الاسم، والرقم أو «📵 رقم غير ظاهر» مع `@username`، والعميل المربوط، و«اسم واتساب» إن اختلف (غير موثّق).
- [ ] ربط بعميل / تغيير الربط / فك الربط (E11.8، `canLinkClient`، ليس لمحادثات الإدارة)، وفك الربط بتأكيد.
- [ ] سبب التدخّل، و✅ تمّت المعالجة، و⏸️/▶️ البوت (`canToggleBot`).
- [ ] الوسوم: إزالة بزر ✕ مسمّى، وإضافة من قائمة ما لم يُربط؛ إزالة وسم اختصاصك قد تخرج المحادثة من نطاقك (استطلاع فوري).
- [ ] التوكيل: قائمة الموظفين لمن يملك `canAssign` (وعند الرفض تعود القيمة)، وإلا اسم الموكَّل نصاً.

## المنشئ
- [ ] مسودة لكل محادثة (`useDrafts`، Q.1) لا تنتقل لغيرها، وتُمسح بعد الإرسال الناجح.
- [ ] تنبيه النافذة المغلقة، والوقت الباقي ≤6 ساعات.
- [ ] 📵 بلا رقم ووضع «حفظ فقط»: لا إرسال. وفي staff/full زر «📱 طلب الرقم» (E11.6).
- [ ] تعطيل الإرسال عند إغلاق النافذة أو أثناء الإرسال أو تعذّر الوصول.
- [ ] رقم المحادثة يُثبَّت لحظة الضغط.
- [ ] 409 `POLICY_WARN` (E15.9): تأكيد صريح ثم إعادة الإرسال مع `ack_warnings`؛ الرفض يظهر «لم تُرسل الرسالة».
- [ ] رسائل الخطأ عربية؛ 403 بنص إنجليزي من Laravel يصير «ليست لديك صلاحية لهذا الإجراء».
- [ ] لا صلاحية رد: «لا تملك صلاحية الردّ على المحادثات».

## الطوارئ والتوقيت
- [ ] `visibilitychange` إلى ظاهر: استطلاع فوري.
- [ ] عند مغادرة الصفحة: إيقاف المؤقتات وإبطال الطلبات المعلّقة (`seq++`).
