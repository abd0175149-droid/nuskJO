# خادم MCP للقراءة (E40)

خادم يقرأ منه مساعد ذكاء اصطناعي (Claude Code) تقارير نسك الداخلية. للقراءة وحدها: لا أداة كتابة ولا إرسال، ولا أي محتوى أو عدّاد من واتساب، ولا أرقام هواتف.

## الشروط قبل التفعيل

1. **Cloudflare Access** أمام `/mcp/*`: تطبيق Self-hosted بسياسة Service Auth وservice token. يحفظ المالك القيمتين خارج المستودع.
2. في `.env.production`: `MCP_CF_TEAM_DOMAIN` (مثل `team.cloudflareaccess.com`) و`MCP_CF_AUD` (وسم AUD للتطبيق). بلا ضبط يرد الخادم 404 على الإنتاج.
3. العلم `mcp_server` (يبدّله المدير وحده). مطفأً يرد `/mcp/owner` بـ 404.
4. صلاحية `mcp.use` (المدير وحده افتراضياً) لإنشاء الرموز.

## الطلب

- `POST /mcp/owner` بـ JSON-RPC 2.0 (Streamable HTTP، رد JSON واحد بلا SSE). GET وDELETE يردان 405.
- الترتيب: العلم (404)، ثم Cloudflare Access (404)، ثم الرمز (401 أو 403)، ثم 30 طلباً في الدقيقة لكل مستخدم (429).
- الطرق: `initialize` و`ping` و`tools/list` و`tools/call`. الإصدارات `2025-06-18` و`2025-03-26` و`2024-11-05`.
- خارج مجموعة web: لا جلسة ولا CSRF. وترويسة `Origin` إن وُجدت يجب أن تكون مضيفنا.

## الرموز

- من تبويب «رموز MCP» في صفحة التكاملات، بعد تأكيد الهوية. الاسم والمدة حتى 30 يوماً.
- القدرة `mcp:read` وحدها. يُعرض النص مرة واحدة بصيغة `id|njmcp_…`، ويُحفظ في القاعدة كبصمة sha256.
- المخطط مخطط Sanctum نفسه (`personal_access_tokens`) بلا الحزمة، فالانتقال إليها لاحقاً بلا ترحيل.
- الإبطال من الصفحة فوري. وتعطيل المستخدم أو إعادة تعيين كلمة مروره أو عامله الثاني أو حذفه يحذف رموزه.
- المستخدم بلا `mcp.use` أو المعطّل لا يمر ولو كان رمزه صالحاً.

## الأدوات

| الأداة | الصلاحية | ما تعيده |
|---|---|---|
| `daily_summary` | `reports.view` | فواتير اليوم ومقبوضاته وما ينتظر الاعتماد ومسافرو اليوم، بلا عدّادات واتساب |
| `sales_report` | `reports.employee_profit` | المبيعات والربح وأعلى البائعين لفترة حتى 366 يوماً |
| `travelers` | `reports.trip_date` | المسافرون بتاريخ، بلا هواتف، 30 حداً أقصى |
| `pending_approvals` | `invoices.approve` أو `receipts.approve` أو `disbursements.approve` | ما ينتظر الاعتماد (لا تعتمد شيئاً) |
| `open_quotes` | `quotes.view` | رقم الطلب ونوعه وحالته وعنوان العرض والمسند إليه ووقته، بلا نص الطلب ولا اسم العميل |
| `find_client` | `clients.view` | بالاسم أو الرمز وحدهما: الرصيد وآخر ثلاث فواتير، بلا هاتف ولا بحث بالهاتف |

- كل أداة تحمل `#[IsReadOnly]` و`#[IsIdempotent]`، ومدخلاتها بمخطط صارم.
- لا تظهر في `tools/list` أداة لا يملك المستخدم صلاحيتها، واستدعاؤها يُرفض كأداة غير موجودة.
- النتيجة 20KB حداً أقصى (تُقص القوائم مع `truncated`).
- كل استدعاء يكتب `mcp.tool_call` في التدقيق: اسم الأداة وبصمة المدخلات وحالتها، بلا النتيجة.
- التقارير من `App\Services\Reports\OwnerReports` نفسها التي يستعملها المساعد الإداري على واتساب، بقيم مقيّدة.
- يحرس ذلك `McpArchitectureTest` و`McpServerTest`.

## إعداد Claude Code

ملف `.mcp.json` محلي خارج أي مستودع (لا يُتتبع):

```json
{
  "mcpServers": {
    "nusk-reports": {
      "type": "http",
      "url": "https://<مضيف نسك>/mcp/owner",
      "headers": {
        "Authorization": "Bearer <الرمز>",
        "CF-Access-Client-Id": "<من Cloudflare>",
        "CF-Access-Client-Secret": "<من Cloudflare>"
      }
    }
  }
}
```

- الصفحة تعرض هذا الملف بالرمز لحظة إنشائه.
- لا تجمع هذا الخادم في جلسة واحدة مع خوادم تملك أدوات كتابة أو إرسال: أسماء العملاء وعناوين العروض بيانات لا تعليمات.
- موصلات claude.ai البعيدة غير مدعومة في هذه المرحلة: تتوقع OAuth ولا ترسل ترويسات Cloudflare. دعمها قرار لاحق (OAuth 2.1 مع PKCE).

## خدمة MCP الرسمية من ميتا

لا تُعطى رمز الإنتاج ولا WABA الإنتاج أبداً. تُستعمل مع تطبيق تجريبي وحده، لأن أدوات ضبط الويبهوك فيها قد توجّه ويبهوك الرقم الحي بعيداً عن نسك.
