# صلاحيات أدوات البوت حسب المرسل (منذ 2026-11-06)

يحدد ملف المرسل ووضع الرقم أي أداة يُعلنها البوت للمحادثة.

- **الملف:** يحسبه `App\Services\WhatsApp\Bot\SenderProfile`.
- **وضع الرقم:** `wa_channels.bot_mode`.
- **الإعلان والتنفيذ:** ما لا يحق للمرسل لا يُعلن للنموذج، وToolInvoker يرفض أي أداة غير معلنة.

## الملفات

يُحسب الملف من الهاتف القادم في webhook موقّع وحده، فلا يرقى أحد بادعاء.

| الملف | الشرط |
|---|---|
| `admin` | رقم إدارة مسجّل. يخدمه المساعد الإداري بصلاحيات رقمه (`AdminTools`) |
| `traveler` | عميل مربوط بالهاتف، له فاتورة معتمدة، واليوم بين `trip_date−1` و`تاريخ العودة+1` (أو `trip_date+15` إن لم يكن تاريخ عودة) |
| `client` | عميل مربوط بالهاتف (`financialClientId`) |
| `lead` | له طلب تسعير مفتوح خلال 60 يوماً |
| `guest` | أي مرسل آخر |

## المصفوفة الافتراضية (`Bot\ToolPolicy::DEFAULTS`)

- **للجميع:** العروض وتفاصيلها وبطاقتها، والموضوع، وطلب التسعير وتأكيد الحجز، والملاحظة، والموقع والبطاقة، والقوائم، والتحويل لموظف.
- **للعميل والمسافر:** الرصيد والفواتير والرحلات، و`resend_invoice_pdf`، و`get_trip_details`، و`report_issue`.
- **للعميل المحتمل والعميل والمسافر:** `get_my_quote_status` و`manage_my_notifications`.

تعديلات المدير تُحفظ فرقاً عن الافتراضي في `wa_bot_settings.tool_profiles` من صفحة «صلاحيات البوت». أداة `handoff_to_human` لا تُطفأ أبداً.

## وضع البوت لكل رقم

| الوضع | الأثر |
|---|---|
| `full` | المصفوفة كما هي |
| `limited` | `handoff_to_human` و`set_topic` و`save_note` والموقع والبطاقة وحدها، وتعليمة «لا تبِع ولا تسعّر». مناسب لرقم الإشعارات |
| `off` | لا يرد البوت. المحادثة «تحتاج تدخّلاً» بسبب `bot_off` |

## الأدوات الجديدة

| الأداة | الحدود |
|---|---|
| `get_my_quote_status` | طلبات المحادثة أو العميل نفسه خلال 90 يوماً |
| `resend_invoice_pdf` | فاتورة معتمدة لـ `financialClientId` نفسه، وثلاث مرات في اليوم للمحادثة. تُرسل رداً لا عبر الطابور |
| `get_trip_details` | الرحلات القادمة والجارية من الفواتير المعتمدة، وملخص العرض (`toBotSummary`، بلا تكلفة) |
| `report_issue` | ملاحظة، وتحويل كامل، وسبب `trip_issue`، وتنبيه فوري للإدارة |
| `manage_my_notifications` | كتم رسائل النظام أو رفعه للعميل، لكل الرسائل أو لمجموعة |

## الخيارات

لا أزرار في واتساب ويب، فالقوائم والأزرار تصل العميل نصاً مرقماً (`OpenWa\PayloadMapper`).

- **رد العميل.** يرد برقم الخيار (1، 2، ٣) أو بعنوانه حرفياً.
- **الحل.** `ChoiceResolver::numbered` يحوّل الرد إلى معرّف الخادم `ch:{nonce}:{key}`، ثم تمر الفحوص نفسها: المجموعة، والحداثة، والصلاحية، والتوفر الآن.
- **سياق الرقم.** الرقم يُفهم على آخر رسالة خيارات وحدها، بشرط ألا يكون بعدها رد آخر منا.
